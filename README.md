# TrekNexa

### An Intelligent, Context-Aware and Safety-Oriented Heritage Trekking Route Recommendation System

TrekNexa is a web-based system designed to recommend suitable heritage trekking routes based on user context, route characteristics, weather conditions, and safety-related factors.

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
